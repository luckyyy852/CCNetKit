# CCNetKit · CC护航 使用说明

CCNetKit · CC护航主要用于 Claude Code 的本机网络适配与专用线路配置，连接查询、域名管理和其他软件分流是配套功能。

Windows 使用桌面窗口；Mac 使用本机浏览器界面，两者的搜索和域名按钮用途相同。Mac 不会弹出 Windows 管理员许可，也不提供月度用量或 Windows 专用守卫功能。

安装后，Windows 打开安装目录的 `bin/Workbench.exe`；Mac 双击 `Open Workbench.command`。关闭管理界面不会停止原代理；是否开机连接由原客户端或已配置的启动任务决定。

配置完成时，AI 应交付实际打开入口、连接及保护结果、是否开机连接和故障恢复方法。更新技能不会自动升级管理程序；已有安装交给 AI 保留私人设置和域名记录后更新，不反复安装或删除旧目录。

输入框支持软件名、域名、完整网址，输入后自动查询。蓝色为代理线路，DIRECT 为直连；没有记录不代表断网。

两端都显示当前和近期连接；Windows 窗口另有规则记录。近期只包含本次打开后已采集的连接，不持久保存；Windows 的规则累计命中不表示当前仍在线。

安装配置时，skill 会一并处理 Claude 的登录跳转、图片和附件等相关连接，并检查它们走指定线路，不需要你逐个补域名。普通浏览器也能使用；需要时会配置同一浏览器的独立窗口，让该窗口的网页请求统一走指定代理，其他日常窗口沿用原设置。请通过配置好的入口使用，Claude 网页与 Claude Code 本机程序分别验证。

需要更独立的登录环境时，可使用已有指纹浏览器；没有的用户无需额外安装。专用窗口中打开的其他网站也会使用同一代理；这不替代防直连保护，也不保证免除登录验证。

修改域名：输入网址或域名，点击“设为国内直连”或“恢复默认分流”，等待结果后刷新网站。Windows 窗口会显示规范化后的目标，出现管理员提示时允许后继续，取消则不改规则；Mac 遇到权限不足会拒绝修改，不自动提权。

恢复默认只撤销本工具管理的额外规则，预设与父域名设置仍适用，不保证一定改走代理。

Windows 的“检查日常配置”只查本机 API、身份和模式；Mac 用“刷新”更新状态。两者都不自动修复全网、不改系统代理、不解除专用保护。

Windows 可选接入 KiwiVM 月度用量查询，API 密钥在本机输入和保存。

网络保护不会自动阻止 Claude Code 读取项目文件。敏感文件需要单独设置访问权限；配置中的 ProtectedFiles 用于防止本工具修改指定文件，不是防读开关。

考虑到中国用户使用 Grok Bot 云端电脑时需要访问国内外网站，提供 Grok Bot 专用分流设置。如需让云端流量使用本机线路，请先在 Bot 中开启“经此电脑转发流量”，并允许云端电脑出站；接入后才会按配置好的规则自动分流，其他软件继续沿用原规则。

开关显示“已启用但尚未转发”时，表示仍在等待云端接入，并未开始转发。这个开关需要用户在 Bot 中开启，skill 不会自动打开。“在这台电脑上执行”是本机任务权限，不是流量转发开关。

Grok Bot 等软件的专用代理入口与进程规则由技能内的“按软件分流”流程设置，窗口的域名按钮不会自动撤销它们。已有进程规则可能优先于域名例外，核对实际新连接，不仅看设置提示。

专用保护需要先完成隔离与本机验收。可选换网守卫使用独立的专用核心，锁定后通过其明确的 Resume 入口手动恢复；窗口只查看状态，不会自动解锁。守卫未运行、未入箱或尚未验证的情况，不能仅凭窗口有绿色状态就认定无法直连。
