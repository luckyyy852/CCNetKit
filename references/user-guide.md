# 离线使用说明

本工具主要用于 Claude Code 的本机网络适配与专用线路配置，连接查询、域名管理和其他软件分流是配套功能。

Windows 使用桌面窗口；Mac 使用本机浏览器界面，两者的搜索和域名按钮用途相同。Mac 不会弹出 Windows 管理员许可，也不提供月度用量或 Windows 专用守卫功能。

输入框支持软件名、域名、完整网址，输入后自动查询。蓝色为代理线路，DIRECT 为直连；没有记录不代表断网。

结果区分当前连接、近期连接和规则记录。近期只包含本窗口已采集的连接，关闭后不保留；规则累计命中不表示当前仍在线。

安装配置时，skill 会一并处理 Claude 的登录跳转、图片和附件等相关连接，并检查它们走指定线路，不需要你逐个补域名。普通浏览器也能使用；需要时会配置同一浏览器的独立窗口，让该窗口的网页请求统一走指定代理，其他日常窗口沿用原设置。请通过配置好的入口使用，Claude 网页与 Claude Code 本机程序分别验证。

需要更独立的登录环境时，可使用已有指纹浏览器；没有的用户无需额外安装。专用窗口中打开的其他网站也会使用同一代理；这不替代防直连保护，也不保证免除登录验证。

修改域名：输入网址或域名，点击“设为国内直连”或“恢复默认分流”。旁边显示规范化后的目标。允许 Windows 管理员提示后等待结果，再刷新网站。取消许可不改规则。

恢复默认只撤销本工具管理的额外规则，预设与父域名设置仍适用，不保证一定改走代理。

“检查日常配置”只查本机 API、身份和模式，不自动修复、不改系统代理、不解除专用保护。

Windows 可选接入 KiwiVM 月度用量查询，API 密钥在本机输入和保存。

考虑到中国用户日常会在国内直连与海外代理之间切换，因此增加 Grok Bot 专用分流设置，让它使用自己指定的代理入口和节点，其他软件继续按原规则分流。

Grok Bot 等软件的专用代理入口与进程规则由技能内的“按软件分流”流程设置，窗口的域名按钮不会自动撤销它们。已有进程规则可能优先于域名例外，核对实际新连接，不仅看设置提示。

专用保护需要先完成隔离与本机验收。可选换网守卫使用独立的专用核心，锁定后通过其明确的 Resume 入口手动恢复；窗口只查看状态，不会自动解锁。守卫未运行、未入箱或尚未验证的情况，不能仅凭窗口有绿色状态就认定无法直连。
