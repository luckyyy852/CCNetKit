# CCNetKit

**Claude Code 专用网络适配助手。** CCNetKit 使用你自己的 VPS、兼容订阅或代理服务，为 Claude Code 配置专用线路，同时保留原有日常网络和网站中转。

同一个 skill 自动识别 Windows 和 Mac，私人节点与配置只保存在本机。国内直连、海外代理、连接查询、网站规则和其他软件分流是配套功能；Windows 与 Mac 的保护能力差异见下文。

## 怎么使用

把整个文件夹放进 AI 编程工具的技能目录，或让它读取 `SKILL.md`，然后说：

> 使用 $windows-network-workbench，识别我的系统，使用我自己的节点为 Claude Code 配置专用网络并安装管理界面，保留已有保护、日常分流和网站中转，不上传私人配置。

没有现成网络时，也可以让 skill 帮你安装配置 Mihomo。支持自建 VPS 节点、兼容订阅、SOCKS5 和 HTTP / HTTPS 代理。已有节点时，通常在本机提供节点分享链接或兼容订阅即可；手动填写则需要协议、服务器地址、端口和认证信息（如密码或用户 ID），部分协议还需要公钥等附加参数。IP 只是服务器地址，服务器上还需有已配置好的代理服务。

这是供 AI 编程工具执行的技能和源码包，需要本机配置，不是双击就能完成全部部署的安装器。

**配置 Claude Code 专用网络前，请自行准备尽可能干净、稳定的代理出口 IP，尽量避免有滥用记录或大量共享的出口。** 本工具负责分流与连接保护，不能改善 IP 信誉，也不保证免除平台验证。

## Windows 和 Mac

| 系统 | 管理界面 | 环境要求 |
| --- | --- | --- |
| Windows 10/11 | 桌面窗口 | PowerShell 5.1、.NET Framework 4.x |
| macOS | 本机浏览器界面 | Python 3.10 或更新版本、现有浏览器 |

安装管理界面本身不切换网络，不启动代理，不改开机设置。已有代理优先复用，避免同时开启两个 TUN；需要接管网络时由 skill 按当前环境配置。

Mac 支持安装、连接查询、搜索、域名直连和恢复默认功能，目前尚未完成真机验证。月度用量和附带的专用核心守卫仅 Windows 提供。Mac 严格防直连需要另行接入并验证系统出站隔离，不能仅靠代理设置保证。

## 平时怎么用

在搜索框输入软件名、域名或网址，查看当前及近期连接：**蓝色代表代理，黑色代表直连**。输入网站后，可点“设为国内直连”或“恢复默认分流”；恢复默认只移除本工具添加的规则，保留原有例外和中转。

Claude 的登录跳转、图片、附件等相关路线由 skill 一并配置和检查。普通浏览器即可使用；需要时使用独立浏览器窗口和指定代理，已有指纹浏览器也可接入，无需额外安装。独立代理窗口里打开的其他网站同样会走该入口。

考虑到中国用户日常会在国内直连与海外代理之间切换，因此增加 Grok Bot 专用分流设置，让它使用自己指定的代理入口和节点，其他软件继续按原规则分流。
